# ロードマップ

前提: 週12時間 / 資金100万円 / 実績ゼロ / 開発力あり。

---

## フェーズ0: 土台づくり（Day 1〜14 / 計24時間）

この2週間の目的は「請求書を出せて、メールが届く状態」を作ること。
ここを飛ばすと、初受注のときに入金できずに商談が流れる。

| Day | やること | 時間 | 完了条件 |
|---|---|---|---|
| 1-2 | 開業届＋インボイス登録番号の申請 | 2h | e-Taxで申請済み。法人は後でよい |
| 1-2 | 屋号の銀行口座を開設 | 2h | 口座番号がある |
| 3 | **営業用ドメインを本番と別に取得** | 1h | 例: 本番 `xxx.co.jp` / 営業 `xxx-jp.com` |
| 3-4 | SPF / DKIM / DMARC を設定 | 3h | mail-tester.com で 9点以上 |
| 5-6 | 1枚もののLP（実績欄は空のまま出す） | 4h | 何ができるか・いくらか・誰宛かが書いてある |
| 7 | 契約書と見積書のテンプレを用意 | 2h | 業務委託基本契約＋個別契約の2本 |
| 8-9 | 請求と決済の導線 | 2h | 銀行振込＋Stripe（カード払いの選択肢があると決裁が早い） |
| 10-12 | `cashman` のセットアップと初回リスト作成 | 6h | `dashboard` が動き、リードが100社入っている |
| 13-14 | ドメインのウォームアップ開始（5通/日） | 2h | 知人・自分宛に送って着信を確認 |

**この時点での支出**: ドメイン2,000円 + メール基盤 3,000円/月 + LLM API 5,000円/月 程度。
資金100万円はまだほぼ手つかずで残る。

### 法人化について

**最初は個人事業でよい。** 法人化は「月商が安定して80万円を超えたら」か
「取引先に法人格を求められたら」のどちらか早いほう。
先に作ると、維持費（年間7万円の均等割＋税理士費用）が売上ゼロの期間に効いてくる。
ただし**相手が上場企業・大手の場合は個人事業だと与信で弾かれる**ので、
そこを狙うなら Day 1 に合同会社を作る（6万円、1週間）。

## フェーズ1: 最初の3件（Day 15〜90 / 月52時間）

目的は売上ではなく **「事例」と「型」**。ここで得た事例が、以降すべての営業で効く。

### 毎日のルーチン（20分）

```bash
python3 -m cashman ingest data/leads_$(date +%Y%m%d).csv   # リード投入
python3 -m cashman score                                    # 再スコアリング
python3 -m cashman draft --limit 40                         # 下書き生成
python3 -m cashman send --live                              # 枠の分だけ送信
```

### 毎週のルーチン（30分）

```bash
python3 -m cashman dashboard     # 返信率・商談化率・日給
python3 -m cashman deal board    # 放置されている商談を潰す
```

### 最初の3件は「安く売っていい」

通常は単価が最重要だが、**最初の3件だけは例外**。
理由は、事例が無い状態では単価を主張する根拠が無いから。

| 件数 | 価格 | 交換条件 |
|---|---|---|
| 1件目 | 初期費0円 + 月額5万円 | 実名・数字入りの事例公開の許諾 |
| 2件目 | 初期費15万 + 月額10万円 | 事例公開の許諾 |
| 3件目 | 初期費30万 + 月額15万円 | 紹介1社 |
| 4件目以降 | 初期費30万 + 月額15万円 | 値引きしない |

1件目を無料に近くするのは値引きではなく、**事例という資産を買っている**。
「月92時間が4時間になった」という実名事例1本は、以降の返信率を1.5〜2倍にする。
これは広告費に換算すれば数十万円の価値がある。

### 90日目の目標

| 指標 | 目標 | 未達なら |
|---|---|---|
| 送信数 | 1,500通 | ウォームアップの遅れ。リスト供給を疑う |
| 返信率 | 4%以上 | 文面ではなくターゲットを疑う（→ `03-acquisition.md`） |
| 商談 | 15件以上 | 返信後の初動が遅い。24時間以内に返す |
| 受注 | 3件 | 価格ではなく提案の具体性を疑う |
| MRR | 30万円 | — |

## フェーズ2: 型の反復（4〜10ヶ月目）

やることは増やさない。**フェーズ1と同じことを、精度を上げて繰り返すだけ。**

| 月 | 顧客数 | MRR | 日給 | この月の主題 |
|---|---|---|---|---|
| 4 | 7社 | 105万 | 4.6万 | 業種を1つに絞る（最も受注率が高かった業種） |
| 6 | 10社 | 155万 | 6.2万 | 構築のテンプレ化。8時間 → 4時間へ |
| 8 | 14社 | 210万 | 7.6万 | 単価を月額20万に引き上げ（新規のみ） |
| 10 | 18社 | 270万 | 9.5万 | **工数の壁。専業化の判断** |
| 11 | 20社 | 300万 | **10.2万** | **日給10万円を達成** |

### 業種を絞る（4ヶ月目）

最初の3件が出た時点で、業種別の受注率を見て**1業種に絞る**。
絞ると次の3つが同時に起きる。

- 文面の具体性が上がる（業界用語と固有の業務名が使える）→ 返信率が上がる
- 構築がテンプレ化する → 8時間が4時間になる
- 事例が効く（同業他社の事例は、他業種の事例の3倍刺さる）

絞る基準は「受注率が最も高い業種」であって「市場が大きい業種」ではない。

### 10ヶ月目の分岐

月52時間が埋まる。ここで3択になる。

| 選択 | 結果 | 向いている条件 |
|---|---|---|
| **A. 専業化する** | 週40時間へ。日給30万が13〜15ヶ月目 | MRRが本業の月収を超えている |
| **B. 構築を外注する** | 副業のまま日給13万が天井 | 本業を辞められない事情がある |
| **C. 単価を上げて社数を絞る** | 顧客20社のまま日給15〜20万 | 専業化も外注もしたくない |

**Cを推奨する。** 専業化の判断を先送りしつつ、日給を5割上げられる。
既存顧客は据え置き、新規のみ月額30〜50万に上げる（→ `docs/02-offer.md`）。

## フェーズ3: 日給30万円まで（11〜15ヶ月目）

専業化を選んだ場合、変えるのは2つだけ。

1. **単価を月額50万円に上げる。** 対象業務を1つから3つに広げ、
   「部門まるごと」の提案にする。月額50万は人件費2人分より安い。
2. **送信数を60通/日に上げる。** ドメインを2本に増やし、片方が焼けても止まらない体制にする。

13ヶ月目に日給30万円（月粗利900万）。この時点で顧客は22社程度。

## フェーズ4: 日給100万円まで（16〜31ヶ月目）

ここからは**事業の性質が変わる**。自分が作るのをやめ、人が作る体制にする。

| 時期 | 採用 | 役割 |
|---|---|---|
| 16ヶ月目 | 構築担当 1人目 | 自分は営業と設計に専念 |
| 19ヶ月目 | 構築担当 2人目 + CS 1人 | 解約率を下げる |
| 24ヶ月目 | 営業 1人 + 構築 1人 | 自分は採用と価格決定のみ |
| 28ヶ月目 | 計7〜8人 | 月商6,000万円規模の運営 |

**粗利率は85%から62%に落ちる。** 人件費が原価に入るため。
それでも日給が伸びるのは、粗利の絶対額が増えるから。
31ヶ月目に顧客71社 × 月額50万円 = MRR 3,550万円、月粗利3,000万円で日給100万円。

### このフェーズで失敗する理由の大半

1. **採用が追いつかない。** 月商3,000万円までに7人を採る必要があり、
   採用そのものが専業の仕事になる。16ヶ月目から採用に月20時間は使う前提で組む。
2. **自分が現場を手放せない。** 品質が落ちるのが怖くて構築を抱え込むと、
   そこで成長が止まる。16ヶ月目は「品質が一時的に落ちるのを受け入れる」月と決めておく。
3. **解約率が上がる。** 顧客が増えるほど目が届かなくなる。
   19ヶ月目のCS採用は、売上に直接効かないが入れないと積み上がらない。

## 各フェーズの撤退・修正基準

数字が出ないまま続けるのが最大の損失なので、先に線を引いておく。

| 時期 | 撤退・修正の基準 | 取る手 |
|---|---|---|
| 3ヶ月目 | 送信1,000通で返信が10件未満（1%未満） | ターゲット業種を変える。文面は触らない |
| 4ヶ月目 | 商談10件で受注ゼロ | 価格ではなく提案内容を疑う。無料の試算提供に切り替える |
| 6ヶ月目 | MRRが50万円未満 | 業務領域を変える（受注処理 → 請求処理など） |
| 9ヶ月目 | MRRが150万円未満 | このモデル自体を見直す。撤退も選択肢 |
| 12ヶ月目 | 日給5万円未満 | 撤退。投下した時間は約600時間、損失は資金の範囲内 |

最悪のケースでも、失うのは**600時間と50万円程度**。
在庫も借入も無いので、撤退コストが低いことがこのルートのもう一つの利点になる。
