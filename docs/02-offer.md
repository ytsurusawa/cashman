# 商品と価格の設計

シミュレータ上、**単価が結果を支配する**（`docs/00-strategy.md` 参照）。
月額7.5万円では3年経っても日給10万円に届かず、月額30万円なら6ヶ月で届く。
したがって設計の起点は「何を作るか」ではなく「どうすれば高く売れるか」になる。

---

## 売り物の定義

| 売り方 | 相場 | 比較される対象 |
|---|---|---|
| ツールとして売る | 月額3〜10万円 | 他のSaaS |
| **業務の代替として売る** | **月額15〜50万円** | **人件費** |

同じものを作っても、どちらの枠で提示するかで価格が3〜5倍変わる。

**だから「AI自動化ツールを提供します」とは言わない。**
「受発注の転記業務が、もう発生しない状態にします」と言う。
前者はSaaSと比較され、後者は派遣スタッフの月給と比較される。

### 提案書に必ず入れる1行

> 現在この業務に **月92時間** かかっています。人件費換算で **月18.4万円** です。
> これを **月4時間** にします。費用は **月15万円** です。

この形にすると、検討が「高いか安いか」ではなく「本当に92時間が4時間になるのか」に移る。
価格交渉ではなく実現可能性の議論になれば、受注率は上がる。

---

## バリューラダー

入口を低くし、実績と信頼が積まれるほど単価を上げる。

| 段 | 商品 | 価格 | 目的 | 工数 |
|---|---|---|---|---|
| 0 | **業務コスト試算レポート** | 無料 | 商談の入口。断る理由が無い依頼 | 0.5h（自動生成） |
| 1 | **スポット自動化** | 15〜30万円 | 小さく始めてもらう | 8h |
| 2 | **自動化＋運用**（主力） | 初期30万 + 月額15万 | MRRの柱 | 8h + 月1.5h |
| 3 | **部門まるごと自動化** | 初期100万 + 月額50万 | 日給30万以降の主力 | 20h + 月3h |
| 4 | **営業システムそのものの提供** | 初期100万 + 月額30万 | アップセル（後述） | 12h + 月2h |

### 段0（無料試算）が効く理由

「資料を送ります」より「御社の業務コストを試算します」のほうが返信率が高い。
理由は、**相手にとっての価値が明確で、断る理由が無い**から。

試算レポートに入れるのは3つだけ。

1. その業務に月何時間かかっているか（ヒアリング値）
2. 人件費換算でいくらか（時間 × 2,000円）
3. 自動化後の想定時間と、差額

A4で1枚。`docs/03-acquisition.md` のシーケンス3通目がこれを提示する。

### 段4: 自分が使っている営業システムを売る

`src/cashman/` そのものが商品になる。

**これが強いのは、自分が実際にそれで受注しているから。**
「このシステムで月800通送って月2件受注しています」という主張は、
相手が今まさにそのメールを受け取って商談している事実が証明になっている。

6ヶ月目以降、既存顧客へのアップセルとして提案する。

## 価格表（フェーズ別）

**既存顧客は据え置き、値上げは新規からのみ適用する。**
既存の値上げは解約を招き、得られる額より失う額のほうが大きい。

| 時期 | 初期費 | 月額 | 根拠 |
|---|---|---|---|
| 1件目 | 0円 | 5万円 | 事例公開の許諾と交換 |
| 2件目 | 15万円 | 10万円 | 事例公開の許諾と交換 |
| 3件目 | 30万円 | 15万円 | 標準価格の確立 |
| 4〜13件目 | 30万円 | 15万円 | 値引きしない |
| 14件目〜（8ヶ月目〜） | 50万円 | 20万円 | 事例が3本たまった時点で引き上げ |
| 11ヶ月目〜 | 100万円 | 30〜50万円 | 対象業務を3つに広げ、部門単位の提案にする |

### 値引きを求められたとき

**価格は下げず、範囲を狭める。**

> 「月15万円は難しい」
> → 「では対象業務を受注処理だけに絞り、月10万円でいかがでしょう。
> 　　請求処理は効果を確認いただいてから追加で。」

値引きすると、その価格が次の商談の基準になって全体が下がる。
範囲を狭めれば、単価は維持したまま入口だけ下げられる。

## 解約を防ぐ設計

シミュレータ上、解約率の影響は単価ほど大きくない（月3%→6%で2ヶ月の遅れ）。
**過剰に対策しない。** 費用対効果が最も高い3つだけやる。

1. **月次レポートの自動送付。**
   「今月この自動化が処理した件数と、削減された時間」を毎月1日に自動で送る。
   効果が見えなくなった瞬間に「これ要る?」が始まるので、見え続けさせる。
2. **年間契約にする（2ヶ月分割引）。**
   月額15万 × 12 = 180万 → 年間150万。解約の判断が年1回になる。
3. **業務に埋め込む。**
   自社システムの中に入り込むほど剥がれにくい。
   独立したツールとして置くと、いつでも止められてしまう。

## 原価と粗利

| 項目 | 月額 | 備考 |
|---|---|---|
| LLM API | 3,000〜15,000円 | 処理件数に比例。顧客への請求に含める |
| サーバ・DB | 3,000〜10,000円 | 顧客が増えても急には増えない |
| メール基盤 | 3,000円 | 送信用 |
| 監視・エラー通知 | 0円 | 無料枠で足りる |

顧客1社あたりの変動費は月5,000〜20,000円程度。**粗利率85%**はここから来ている。

**注意: LLM APIのコストは顧客の処理件数に比例する。**
月間処理件数に上限を設け、超過分は従量課金にすること。
上限なしの定額にすると、処理件数が多い顧客で赤字になる。

```
基本料金  月額15万円（月3,000件まで）
超過分    1件あたり20円
```
